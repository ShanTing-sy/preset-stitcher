# 预设缝合助手

一个 SillyTavern（酒馆）扩展：把多个预设的**提示词条目**、**变量定义**、**正则脚本**缝合成一个新预设，并一键写入酒馆、切换启用。

**不依赖任何其它插件**（不需要酒馆助手）。

---

## 安装

### 方式一：填 Git URL（推荐）

1. 打开酒馆 → **扩展** → **安装扩展**
2. 在输入框里填本仓库地址：

   ```
   https://github.com/ShanTing-sy/preset-stitcher
   ```

3. 点安装 → **刷新页面（F5）**
4. 输入框上方的**魔法棒**菜单里会出现「预设缝合」

> ⚠️ 如果之前手动装过同名文件夹，酒馆会报「目录已存在」。先删掉
> `data/<你的用户名>/extensions/preset-stitcher/` 再装。

### 方式二：手动放置

把本仓库的文件放进：

```
<酒馆目录>/data/<你的用户名>/extensions/preset-stitcher/
```

（文件夹名可以随意，但建议用 `preset-stitcher`）

然后刷新页面。

## 功能

### 三块功能，两种模式

点左上角的「预设缝合 ▾」切换：

| 模式 | 内容 |
|---|---|
| **预设缝合** | 缝提示词条目 **+** 变量（两个子页签） |
| **正则缝合** | 缝正则脚本，随预设绑定同步输出 |

### 缝合槽位（可多个）

顶部的槽位标签就是一份份独立的缝合产出。每个槽位各有自己的骨架预设、目标条目、变量裁决、正则顺序和全局参数。**左键切换，右键**打开菜单：

- 重命名
- 作为新预设同步到酒馆
- 作为待缝合预设导入（把成品当素材，可以缝下一层）
- 删除槽位

### 骨架机制

点左栏预设前的 ☆ 设为**骨架**。骨架决定这些「每个预设只能有一份」的东西：

- 系统提示词（主提示词 / 越狱词 / 增强定义）
- 占位符（角色描述、世界书位置、聊天记录位置…）
- 生成参数

其他预设的这几类内容不会缝进来，避免写入失败。

### 全局参数

左栏底部可以编辑目标预设的生成参数（温度、上下文、Top P/K/A、各种惩罚…）。默认继承骨架预设；**骨架预设本身不带参数时（有些预设确实如此），这里是唯一的参数来源**。

### 变量树

变量关系画成**树杈图**：左边每个变量一条声明节点，右边连着它的各个来源。

- **连线零交叉**——布局按「一个声明后面紧跟它的全部值行」这个不变量排，不靠避让算法
- 值行显示**条目正文的首个非空行**（如 `[内在罗盘：常规]`），点开看完整原文
- 「📜获取变量」这类**只声明不给值**的条目收进顶栏，不再挂满每一根树杈
- 声明卡**垂直居中**于它那组值行，一眼能看出「这一块是它的」
- 命中冲突的变量点值行 → 右栏看完整内容后再决定采用哪个来源的值
- **悬空引用**（被引用但没有定义）的变量在声明处直接补初值。这类问题会让条目**静默失效**，不报错只是不生效
- 产出**一条声明条目**（含所有声明）+ **每个来源一条赋值条目**

树标题栏的 **✨ AI 解析**：让 AI 通读选中的预设，把「没写 `setvar` 宏、但实际在给某个变量赋值」的条目也找出来。结果在弹窗里展示并**标出与现有树的差异**（新增变量 / 新增来源 / 值不同），可以选**查漏补缺**或**覆盖整棵树**，也能随时撤销退回纯扫描。

### 条目比对

AI 生成的结果**不会直接覆盖**目标条目，而是进「条目比对」逐个确认：

- 上半是**旧条目**、下半是 **AI 版本**，中间那根线可以上下拖
- 底部三个按钮：**写入** / **重新生成** / **放弃**
  - 写入 → 目标条目同步为新版，该条从待确认列表消失
  - 重新生成 → 写修改意见让 AI 重做这一条（以当前版本为底，不是推倒重来）
  - 放弃 → 保留原条目

从「AI 助手」列表或中栏的 AI 结果列表点任意一条，都能进这里。

### 条目编辑

点任何条目都能编辑——**目标条目、AI 生成结果、源预设里的条目**，共用同一个编辑器：

- 名称 / 内容 / 启用 / 角色 / 插入方式
- 改源预设的条目改的是**本地快照**，不动酒馆里的原预设
- 条目轨道里**单击一条 = 打开编辑**，行尾的 `＋` 才是加入 / 移出目标（不会手滑就把条目缝进去）

### 正则缝合

- 可拖拽调序（正则按顺序生效，顺序本身就是语义）
- 全字段编辑器 + **实时测试**
- 自动检测冲突：完全重复 / 高度相似 / 作用域重叠

### AI 助手

- **高级设置固定在顶部**，展开后超出高度自带滚动条，不挤走下面的对话框
- **两级筛选**抓取相关条目（粗筛只传摘要压上下文，精判传全文并给理由）
- 抓取前可**限定只在哪几个源预设里找**
- **对齐润色** / **合并同主题**——结果**先存本地**，再进「条目比对」逐个确认（见上）
- 底部是**对话框**：`发送` / `暂停` / `重说`，配 `Ctrl+Enter` 快捷发送
- **注入条目**（作为 AI 的固定参照）：**默认目标栏全部注入**
  - 可以逐条移除、一键清空
  - 也能从**其他源预设**里挑条目注入——它们会**先逐条加进目标预设**，再作为参照
  - 移除注入只影响「给不给 AI 看」，**不会删掉目标条目**
- 生成的条目**存在本地**：关面板、切槽位、重开都不会丢
- 可编辑系统提示词

### 其它

- **日夜主题**：暖黄+浅绿 / 深蓝夜色
- **批量操作**：多选、全选、反选、批量加入或移除
- **一键清空**：全局 / 已导入预设 / 当前槽位 / AI 助手，共四处
- 工作区自动保存

## 已知限制

| 限制 | 说明 |
|---|---|
| 只支持对话补全格式预设 | 即酒馆里 `openai` 那一组 |
| 生成中无法中途打断 | 酒馆原生 `generateRaw` 用的是它内部的 AbortController，外部无法中止。点「停止」会在当前这一条完成后生效 |
| 预设正则需授权 | 酒馆要求预设正则在「扩展 → 正则」里被允许才生效。插件会自动加白名单 |
| 正则部分字段会丢 | 酒馆会把「替换宏」重置为 0，且不保留「推理」作用范围。插件会检出提示 |
| 工作区上限 | 超过 4MB 时只保存缝合结果，源预设快照需重新导入 |

## 更新本扩展

改了代码后：

```bash
# 1. 重新构建（在源码工程目录）
node build-css.mjs
npx --yes pnpm@10 exec webpack --config webpack.extension.mjs --mode production

# 2. 把 dist/预设缝合助手扩展/index.js 复制到本仓库根目录

# 3. 把 manifest.json 里的两处版本号一起 +1
#    "js": "index.js?ver=1.1.1"
#    "version": "1.1.1"

# 4. 提交推送
git add . && git commit -m "v1.1.1" && git push
```

> ⚠️ **不要直接改酒馆安装目录里的文件**（`data/<用户>/extensions/preset-stitcher/`）。
> 那是 git 仓库，手动改会留下本地修改，之后点「更新」时会因为
> 「本地改动会被覆盖」而拉取失败，报 `Extension update failed / Internal Server Error`。
> 要改就改本仓库，再让酒馆更新；万一已经改脏了，用
> `git checkout -- .` 丢弃本地改动后再更新。

版本号很重要：酒馆用 `<script type="module">` 加载扩展，浏览器会强缓存。`?ver=` 变了才会拉新文件。
